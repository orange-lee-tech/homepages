## Core product capabilities

- **Planning** — 将创作意图、参考内容与需求整理为可检查的 ScriptPlan 与 ShootingPlan。
- **Automatic Editing** — 对用户选择的本地视频素材进行媒体理解、镜头匹配、编辑决策、字幕/音频/图形处理、EDL 构建与最终 MP4 渲染。
- 支持 Planning-only、Editing-only 和 Combined 工作流。
