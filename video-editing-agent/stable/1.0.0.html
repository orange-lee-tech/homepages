# 有岐 1.0.0

有岐（video-editing-agent）是一款面向 Windows 的 local-first AI Director + AI Video Editor，主要处理用户自行提供的本地视频素材。

本版本面向短视频、产品展示、电商/商业内容与 Vlog 等场景，核心产品能力包括：

- **Planning** — 将参考内容、商业意图和创作需求整理为可检查的 ScriptPlan 与 ShootingPlan；
- **Automatic Editing** — 对用户选择的本地素材进行媒体理解、镜头匹配、编辑决策、字幕/音频/图形处理、EDL 构建与最终 MP4 渲染；
- 支持 Planning-only、Editing-only 和 Combined 工作流；
- 本软件不会在素材缺失时静默使用网络下载素材或生成素材替代用户原始视频。
